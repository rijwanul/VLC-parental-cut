Skip the parts you don't want to watch.

Assalamualaikum. Watching videos with inappropriate talking points, dialogue and scenes is not suitable for a Muslim. If someone must watch or listen to something for reasons they will answer to Allah for, this tool can help a little to cut out the unwanted portions of media played through VLC, using the playlist method.

Ask an AI to read a subtitle file and list the scenes to skip. Paste its answer here, tick what you want cut, and download a VLC playlist that plays everything else. No install, no re-encoding, and nothing leaves your browser.

How to write the list
  • Each episode starts with a title line ending in a colon, for example Show - S01E02 (Episode title):
  • Skip- starts the ranges that are skipped. Others- starts ranges that stay in unless you tick them.
  • A range is * start-end: note (Level, tags). Times can be 3:30.9, 1:02:03 or plain seconds. The note and brackets are optional. Level is Low, Mid or High.
  • Runtime: 24:10 is optional and makes the timeline exact. Video: name.mkv is optional too.
  • Buffer before and after: 1s widens every skipped range. Put it above the first title to apply it to every episode, or inside an episode for just that one. Buffer before: and Buffer after: set one side.

    Guide

    1. Download the subtitle file

      Get the English .srt for the exact video you have. Pick the one that names your release (for example WEB-DL or BluRay) so the timings line up.

      • SubDL
      • OpenSubtitles
      • Addic7ed

    2. Copy the prompt

      Say what you want skipped. The prompt updates as you type.

    3. Send the prompt and the subtitle file to an AI

      Attach the .srt, paste the prompt and send. If the answer comes back in another format, reply with "use exactly the format from my prompt".

      • Claude
      • Gemini
      • ChatGPT

      The AI site receives your subtitle file and prompt. This page never does.

    4. Paste the answer

      Copy the AI's list and paste it here in the text box. The page below fills in as you paste.

    5. Paste the file names

      Open the folder with your videos, run dir /b in Command Prompt (or tree /f) and paste the output here in the text box. Episodes are matched to files by their S01E02 code.

    6. Check, uncheck and download

      In the builder, tick the ranges to skip, fix any times that land early or late, then download the .m3u. Put it in the same folder as the video and open the playlist in VLC.

    About

    What it does

    VLC can start and stop a file at set times. This page turns a list of skip ranges into a playlist that plays the file in pieces, leaving the skipped ranges out. It never edits your video.

    Privacy

    Everything runs in your browser. Your list and settings are saved only in this browser, so clearing site data removes them. The AI sites in the guide are separate and see what you send them.

    Limits

    An AI reading subtitles sees dialogue only, not the picture, so it can miss things and make judgment calls. Subtitle times match your video only if both come from the same release. Check the first cut of each episode.
